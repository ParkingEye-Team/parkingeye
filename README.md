# ParkingEye · 城市露天停车资源识别与容量估计系统

ParkingEye 面向高分辨率卫星/航空影像，自动识别城市露天停车场地块、检测停放车辆，并结合几何规则推算停车容量，最终以 Web 看板呈现"城市静态交通一张图"。目标用户为城市规划与交通管理部门，作为决策辅助工具。

由 **ParkingEye 团队**（SRTP 项目，5 名学生 + AI 协作）研发。

## 功能维度

| 维度 | 内容 |
|------|------|
| 停车场区域识别 | 语义分割各类露天停车场地块 |
| 停车位与车辆检测 | 旋转框（OBB）定位影像中车辆 |
| 停车容量估计 | 地块面积 ÷ 单车位标准占地 × 布局系数 |
| 停车资源空间评估 | 融合 POI / 路网，分析供需匹配 |

## 仓库结构（Monorepo）

```
parkingeye/
├── ml/          # 算法与训练：影像切片、OSM 标签、OBB 检测、分割管线
│   └── scripts/ # 分步脚本（00–08 + 并行下载器）
├── backend/     # 后端服务与 API（规划中）
├── web/         # Web 看板前端，专题图 / 热力图（规划中）
├── assets/      # 视觉素材（图标、预览页）
├── doc/         # 项目文档（规划、执行计划、标注规范等）
└── data/        # 数据（影像、标注、中间产物，不入库，见 .gitignore）
```

> 遥感影像、训练权重、`.venv` 等大体积或可再生文件不入库，由 `.gitignore` 排除；数据文件按需在本地或团队共享盘获取。

## 技术栈

- 旋转框检测 / 分割：Ultralytics YOLO11-OBB
- 数据与地理处理：GDAL / rasterio、GeoPandas
- 标注：X-AnyLabeling（多边形 + SAM 辅助）

## 快速开始

算法管线脚本位于 `ml/scripts/`，按 `00_check_env.py → 01_tile_imagery.py → …` 顺序执行；各脚本用法见文件头部 docstring，或参考 `doc/` 下的规划与规范文档。
