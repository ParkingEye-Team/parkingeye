# 项目规划与数据获取方案

> 文档版本：v1.0
> 撰写日期：2026-09-05
> 项目：基于高分辨率卫星图像的城市露天停车资源识别与容量估计系统
> 目标城市：成都市

---

## 一、项目背景与目标

随着城镇化推进与机动车保有量激增，停车难已成为制约城市交通效率的治理痛点。传统停车资源调查依赖人工踏勘、静态备案数据或局部视频监控，存在人力成本高、周期长、覆盖范围有限、数据滞后等问题。

本项目面向高分辨率卫星/航空影像中可见的城市露天停车资源，构建一套可交互、可展示的**"城市停车资源识别与容量估计原型系统"**，实现从遥感影像输入到停车资源专题图输出的全链路自动化，以数据看板和热力图呈现城市静态交通家底。

### 四个研究/功能维度

| # | 维度 | 内容 |
|---|------|------|
| 1 | 停车场区域识别 | 复杂城市背景下语义分割出各类露天停车场地块 |
| 2 | 停车位与车辆检测 | 目标检测定位影像中的停放车辆与空闲车位 |
| 3 | 停车容量估计 | 结合停车场几何形态与空间布局规则，推算非标准露天场地最大理论容量 |
| 4 | 停车资源空间评估 | 与 POI、路网数据融合，分析各功能区资源分布与供需匹配度 |

### 现有资源与约束

| 项目 | 状态 |
|------|------|
| 卫星影像 | 无，需采购（预算约 ¥1000–2500） |

## 二、数据获取渠道调研

### 2.1 卫星影像（付费）

| 渠道 | 网址 | 分辨率 | 价格 | 说明 |
|------|------|--------|------|------|
| 星图地球开放平台 | https://open.geovisearth.com/ | 亚米级存档 | 低至 ¥5/km² | 支持按区域/时间订购，即买即得；电话 400-822-6660 |
| 吉林一号网遥感商城 | https://www.jl1mall.com/ | 0.5–0.92m | 低至 ¥13/km²，认证用户 66 折 | 全球最大亚米级商业星座；0.5m"一张图"以半年为周期更新 |

**采购策略**：不采购整个成都市，选取 2~3 个典型片区共约 **100–200 km²**：

- 一个核心商圈（如春熙路-盐市口片区）；
- 一个大型居住区（如城南华阳/大源片区）；
- 一段城乡结合部/绕城边缘区域。

建议分辨率 **0.5–0.8m**（0.5m 下轿车约 20×45 像素，检测可行；2m 级难以分辨车辆）。**预算估算：100–200 km² × 5–13 元 ≈ ¥1000–2500**。

免费备选：天地图四川/成都在线瓦片（约 0.5–1m），但服务条款限制批量下载，仅适合做系统界面底图，不建议用作训练数据。

### 2.2 公开数据集（免费，替代从零标注）

| 数据集 | 用途 | 说明 |
|--------|------|------|
| [DOTA-v1.0](https://captain-whu.github.io/DOTA/dataset.html)（武汉大学） | 车辆检测预训练 | 18 类旋转框，small-vehicle 类实例极多；**有百度网盘下载链接（国内可达）**；学术用途许可。训练管线见 [Ultralytics DOTA-OBB 文档](https://docs.ultralytics.com/datasets/obb/dota-v2) |
| [xView](http://xviewdataset.org/) | 车辆检测（超大规模） | 0.3m WorldView-3 影像，100 万+ 目标、60 类，含多级车辆类别；需官网注册获取 |
| [COWC](https://gdo152.llnl.gov/cowc/) | **车辆计数**（与容量/占用率直接相关） | 15cm 航拍，专为本任务设计，含正负样本；LLNL 服务器直接下载（已验证可达） |
| ISPRS Potsdam/Vaihingen | 车辆分割 | 9–20cm 航拍，含 car 类，德国城市，公开下载 |
| [iSAID](https://captain-whu.github.io/iSAID/) | 航拍语义分割 | DOTA 同源影像的像素级标注，含 car / large-vehicle / small-vehicle 类 |
| [VisDrone](https://github.com/VisDrone/VisDrone-Dataset) | 无人机视角车辆 | 厘米级分辨率，需注册；域与卫星略有差异 |
| [APKLOT](https://github.com/langheran/APKLOT) | 停车区块分割 | 全球真实卫星照片的停车区块分割数据集 |
| PKLot | 车位占用检测 | 经典高分辨率航拍数据集，约 1.2 万个车位标注占用/空闲 |
| OpenStreetMap 成都 `amenity=parking` | 停车场地块弱标签 | 成都已有大量停车场多边形（已拉取 311 个），可作分割模型粗训练标签与验证参照 |

### 2.3 POI 与路网数据（免费）

- **高德开放平台**（https://lbs.amap.com/）：个人认证开发者享 **1 年免费月配额**（2025-05-20 起改为月配额制，超限停用不自动扣费）。使用 POI 搜索 API 拉取成都商圈/住宅/办公类兴趣点。
- **备选**：OSM 的 POI 与路网数据（Overpass API 导出，免费无配额）。

## 三、技术方案（适配 RTX 5070 Laptop 8GB）

### 3.1 模型选型

| 任务 | 模型 | 说明 |
|------|------|------|
| 车辆检测 | YOLOv8n/s-OBB 或 YOLO11-OBB | 先在 DOTA small-vehicle 上预训练，再用成都影像微调 |
| 停车场地块分割 | SegFormer-B0/B2 或 DeepLabV3+（ResNet-18） | OSM 弱标签 + APKLOT 预训练，成都样本精调 |
| 标注辅助 | SAM / SAM2 | 点选式分割辅助人工精标 |

### 3.2 8GB 显存约束下的训练/推理策略

- 训练：512×512 切片输入，小 batch + FP16 混合精度；
- 推理：大图切片推理（SAHI 等滑动窗口 + 合并策略），解决车辆小目标问题；
- 数据预处理与坐标处理：GDAL / rasterio / QGIS；
- 全程本地可跑，无需云 GPU。

### 3.3 标注计划

- OSM 弱标签自动生成大部分停车场分割样本；
- SAM 辅助在成都影像上人工精标 **300–500 个样本**（停车位框/车辆框/地块多边形），用于域适配与测试集；
- 标注工具：X-AnyLabeling 或 CVAT（车辆框）、QGIS（地块多边形）。

## 五、影像分辨率问题与升级渠道（2026-09 补充调研）

### 5.1 现状

- 已通过吉林一号教育认证申领一张 0.5m 影像；实测认为分辨率不足。
- 0.5m 下轿车约 20×45 像素，车辆检测（有无车）可行（DOTA 数据集影像即为 0.3–1m 量级）；**真正的瓶颈是空车位识别、车位线分辨**，需要 0.3m 级影像。

### 5.2 风险提示

闲鱼购入的破解版 Google Earth **不建议继续使用**：影像版权属 Google，答辩/发表/展示存在合规硬伤；截图无地理坐标、比例尺不一致，无法支撑 GIS 融合与批量推理；破解软件本身存在安全风险。

### 5.3 高分辨率正规渠道（按推荐排序）

| 渠道 | 分辨率 | 成本 | 说明 |
|------|--------|------|------|
| 无人机自采 | 2–5cm | 低（需有/租大疆设备） | 最优训练与验证数据源；成都绕城内多为管制空域，需经大疆 App / 民航 UOM 申请解禁，建议城郊合规场地 |
| Pléiades Neo（空客） | 0.3m 原生 | 存档约 $20–22.5/km²，最低 25 km²（约 ¥4000） | 正规解决空车位识别；可直接订购中国区域存档 |
| WorldView-3（Maxar，国内代理） | 0.31m 全色 | 价位与 Pléiades Neo 相当 | 经揽宇方圆等国内代理商购买 |
| 政府航空影像申请 | 0.2m 级 | 免费 | 通过 [webmap.cn（四川省地理信息资源目录服务系统）](https://www.webmap.cn/store.do?method=store&storeId=25) 申请，一般需学校/单位抬头介绍信 |
| Google Earth Pro 官方免费版 | 视角相关，可达 0.1–0.2m/px | 免费 | 单次可存 4800×4800；版权属 Google，仅限内部算法调试，不可公开发布/商用 |

### 5.4 公开图源清单（"免费可见"≠"免费可用"，注意服务条款）

| 图源 | 成都城区有效分辨率 | 定位与限制 |
|------|------------------|-----------|
| Google Earth Pro（官方免费版） | 0.15–0.3m/px | 免费图源天花板；单张最高 4800×4800；版权归 Google，仅限内部调试 |
| Esri World Imagery / [ArcGIS Wayback](https://livingatlas.arcgis.com/wayback/) | 0.3–0.5m | Wayback 存有 2014 年至今数十个历史版本，可作多时相增广 |
| Bing Maps 卫星图层 | 0.3–0.5m | 与 Google 源部分重合 |
| 天地图影像（四川节点） | 0.5–0.8m | 有官方 API key，**作为系统底图合规**（守配额+署名）；原型系统 Web 看板底图首选 |
| 高德/百度卫星图层 | 较高 | GCJ-02 偏移坐标系，与 WGS84 混用会错位；商用条款严格，不作训练源 |
| cpeos 国家遥感平台（高分二号） | 0.8m 全色 + 3.2m 多光谱 | 注册可免费申请；分辨率不及吉林一号，但**含近红外波段**，辅助区分植被/硬化面/车顶 |

**定位**：公开图源用于 ①系统底图（天地图，合规）、②内部算法调试样本（GE Pro 截图 + QGIS 配准）、③多时相增广（Wayback）；训练集主体仍走 0.3m 采购或无人机。不进行大规模瓦片爬取（违反服务条款）。

### 5.5 建议策略

- **组合方案**：小范围核心试点区（≥25 km²）采购 0.3m 影像做算法研发与精度验证；大范围评估区沿用吉林一号 0.5m 影像；有条件则补充无人机航拍样本。
- **先验证再采购**：先核查吉林一号影像实际成片质量，确认痛点是否为空车位识别，再决定是否追加预算。
