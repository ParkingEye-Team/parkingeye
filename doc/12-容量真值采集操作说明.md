# 容量真值采集操作说明（标注组一页版）

> 目的：给 24 个候选停车场数出**真实车位数**，用于校准容量估计引擎并产出误差报告（核心创新点的验证闭环）。
> 工具：**Google Earth Pro 官方免费版**。仅内部使用；截图/坐标**不得**进入公开材料或系统底图。
> 工单：`data/capacity/truth_collection_blind.csv`（24 行，含经纬度；**不含模型估计值，避免先入为主**）。
> 预计耗时：每场地 5–10 分钟，完成 10–20 个约 2–3 小时。

---

## 一、准备

1. 用 Excel 打开 `data/capacity/truth_collection_blind_v2.csv`
   （若看到的是旧版 `truth_collection_blind.csv`，缺少 `is_parking` 列，请以 `_v2` 为准）。
2. 确认列：`lot_id, lon, lat, area_m2, split, is_parking, true_capacity, layout_true, notes, collected_by, date`。
3. `split` 已分配：**calib = 校准集**（用来调系数），**test = 测试集**（最终只评估一次，不要拿来调参）。优先做 calib。

## 二、逐场地操作（GE Pro）

1. 打开 GE Pro，在搜索框输入坐标，格式：`纬度, 经度`，例如 `30.718342, 103.993509`，回车定位。
2. 放大到能看清车位线（视角高度约 **100–300 m**；若影像模糊，换时间段影像或记录"不可判读"）。
3. **先判定"是不是停车场"（新增，最重要）**：
   - `is_parking` 填 `是` / `否` / `不确定`。
   - 判定为**否**的典型情况：报废车/车辆堆场、工地、物流货场、厂区空地、三层围合但无车位线且无实际停车行为的区域。
   - 填 `否` 时：`true_capacity` 填 `0`，`notes` 写清原因（如"车辆堆场，非公共停车场"）。
   - 填 `不确定` 时：`true_capacity` 留空，`notes` 说明疑点，由第二人复核。
   - 只有 `is_parking=是` 的场地才参与容量校准与误差评估；`否` 的场地会进入排除清单。
4. **数车位**：
   - 有清晰车位线：按格子数（斜列/垂直/平行都数）。
   - 无标线：按"能停一辆车的完整位置"数，**宁少勿多**，不要为凑数把通道、绿化、出入口算进去。
   - 只数**地面露天**车位；地下车库、立体车库、带顶棚车棚**不算**。
5. 填写：
   - `true_capacity`：整数（主估计值）。
   - `layout_true`：`垂直式` / `平行式` / `斜列式` / `不规则`（混合时写主要类型，如"垂直式为主"）。
   - `notes`：不确定范围、树荫遮挡、边界不清、改扩建等（例："约 180–200，东侧树荫遮挡"）。
   - `collected_by`：姓名；`date`：采集日期（YYYY-MM-DD）。
6. 若场地与坐标偏差很大（例如坐标落在建筑上），在 `notes` 写"坐标偏移"，并跳过。

## 三、判定口径（避免争议）

| 情况 | 处理 |
|------|------|
| 车位线清晰 | 按线数格子 |
| 无车位线、地面划线模糊 | 按可停车位置数，宁少勿多 |
| 树荫/建筑遮挡 | 数可见部分 + 合理推测，`notes` 注明范围和遮挡程度 |
| 地下/立体/顶棚车库 | 不算 |
| 正在行驶的车 | 不算车位；只数停放位置 |
| 场地内有通道/绿化/出入口 | 不算车位 |
| 影像日期与卫星影像不同 | 容量按"设计车位数"数；若明显改扩建，`notes` 注明 |
| **车辆堆场/报废车场/工地/货场** | **`is_parking=否`，不计容量** |

## 四、质量要求

- **不要看模型估计值**（盲采工单已去掉该列），先独立数完再比对。
- 每个场地至少自检一遍；抽查 20% 由第二人复核（差异 >20% 时第三人裁定）。
- test 集的 7 个场地**只数一次、不要反复调**，否则测试集会被"调参污染"。

## 五、交回

2. 告诉我（或提交到仓库），我会：
   - 把 `is_parking=否` 的地块写入 `data/capacity/exclude_lots.csv`，重跑容量引擎（排除项不计入总数）；
   - 用 calib 集拟合单车位综合占地系数（按布局）；
   - 在 test 集上报告 MAE / MAPE / 平均偏差；
   - 更新 `doc/06` 与结题材料的容量误差数字。

> 说明：`data/capacity/exclude_lots.csv` 是人工排除清单（列：`lot_id,reason`），引擎运行时会自动剔除这些地块；当前为空模板，等核实后由我填写。若你发现某地块明显不是停车场，也可以直接在该文件里加一行。

> 提醒 1：这份真值只用于**容量校准**，不用于车辆检测训练；两者口径不同（容量 ≠ 当前车辆数）。
