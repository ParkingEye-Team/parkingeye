# 吉林一号域车辆标注工作台（模型辅助标注）

> 目的：用**吉林一号自己的影像**标注 + 微调，解决"GE 域微调无法迁移到吉林一号"的域差异问题（见 doc/05 第八节）。
> 生成时间：2026-10-10；生成脚本：`ml/scripts/20_preannot_jl1.py`

## 为什么这么做

- 已证明：GE 截图微调对吉林一号**负迁移**（域本质差异，数据量不是原因）。
- 正确解法：**在吉林一号影像上标注少量数据，直接做域适配微调**。
- 已证明：DOTA 基线在吉林一号上"**框出来的都是车**"（精度高、召回低）。
- 所以采用**模型辅助标注**：模型先框好（预标注），你们只做两件事——**删误检 + 补漏检**。比从零画框快 3–5 倍。

## 怎么标（每个窗口约 10–20 分钟）

1. **拷贝一份工作副本**（保留 `preannot_raw/` 不动的原始备份）：
   把 `images/` 和 `preannot_raw/` 里的文件复制到 `data/jl1_annot/<场景>/work/`（可自建），在 work 里操作。

2. **用 X-AnyLabeling 打开**：File → Open Dir，选 `work/` 目录；或拖入单张 JPG（JSON 会随同名自动加载）。

3. **逐窗口修正**（目标：让这一张图变成"全对"）：
   - **删误检**：框没框在车上（少数）→ 删掉。可先看框上的 score，低分的重点检查。
   - **补漏检（重点）**：停车场里没被框出的车 → 用 `Rotation` 旋转框补上。**这是主要工作量**，模型在密集处漏得多，你补的每一辆都在教模型"这里还有车"。
   - **修正框**：明显过大/过小/角度歪的，拖动调整。
   - **模糊车（宁缺毋滥）**：完全糊成一团的、看不清是不是车的**不补**；轮廓能推断的（哪怕压在阴影里）要补，那是困难样本。
4. **保存**：Ctrl+S（保存 JSON，覆盖回同名文件即可）。

5. **完成标准**：一张图里**所有清晰可见的车**都被框住且框贴合。别追求 100% 完美，但也别只改两三处就过。

## 标完交回

1. 把 `work/`（或你工作的目录）里所有 JSON 交回（告诉我路径即可，或放回 `data/jl1_annot/<场景>/work/`）。
2. 我运行转换 → 在 DOTA 权重上做**吉林一号域微调** → 三域评估（JL1 冬季/夏季/GE 留出）。
3. 预期：吉林一号上召回明显提升（这次域是对的方向）。

## 参考：目前 JL1 上的检测现状（你标注时看到的现象）

- 公路/稀疏区：检得不错，偶尔漏；
- 密集停车场：框出 30%–50%，大部分车相互融合、模型漏检——**这正是需要你补的区域**；
- 极暗/死区：不标（无效区域）。
