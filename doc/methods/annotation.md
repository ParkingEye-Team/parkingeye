# 停车场人工标注规范（X-AnyLabeling）

> 标注对象：冬季吉林一号 0.5m 影像内的露天停车场（CLAHE 增强辅助图）
> 工具：X-AnyLabeling（免费开源，多边形标注，CPU 版即可）
> 产出：每张图一个同名 JSON（LabelMe 兼容格式，像素坐标多边形）
> 本任务由 标注组 2 人 完成

## 一、目标

在 `data/annot_aux/lot_*.png`（50 张 1024×1024 增强图）中，用 X-AnyLabeling **精确勾勒每个可见露天停车场的边界多边形**，用于训练停车场地块语义分割模型。

## 二、安装

1. 到 GitHub 下载 Windows 版：
   `https://github.com/CVHub520/X-AnyLabeling/releases`（选 v4.0.6）
2. 下载 **CPU 版**即可（多边形标注用不到 GPU 推理）：
   `X-AnyLabeling-v4.0.6-CPU.exe`（约 371 MB）
3. 双击解压/安装，运行 `X-AnyLabeling.exe`。

## 三、标注规则

1. **框什么**：图中**所有可见的露天停车场**。判断标准：
   - 大块灰色/深色硬化地面，可见成排车辆或地面标线；
   - 周边有明显边界（道路、绿化、围墙、建筑）分隔；
   - 排除：地下/立体停车库入口、道路本身、建筑屋顶、工地。
2. **每个停车场一个独立多边形**（label 填 `parking`，所有停车场统一用这一个标签）。
3. **贴合边界**：沿停车场地面的实际边缘勾勒，贴合硬化地面与周边（绿化/道路/建筑）的分界线，**不要框进周边绿化或建筑**。
4. **一辆车不标、车位线不标**——只标地块轮廓（这是分割任务不是检测）。
5. **看不清就不标**：疑似停车场太小/太暗/被树遮挡而无法确定边界，**跳过**，不要瞎标。
6. **整张图没有停车场**：不画，直接切下一张。

## 四、操作步骤

1. 打开 X-AnyLabeling → File → Open Dir 选择 `data/annot_aux/` 目录；
2. 左侧工具栏选 **创建多边形**（Create Polygons，快捷键 P）；
3. 沿停车场边界**逐个顶点单击**，闭合后双击/回车结束；
4. 弹出标签框输入 `parking`，确认；
5. 一张图多个停车场就重复 2–4；
6. 保存：Ctrl+S（每张图生成同名 `.json`）；
7. 切下一张：Ctrl+滚轮 / 文件列表。

## 五、完成后检查

- `data/annot_aux/` 下应有 **约 50 个 `.json`**（每张图一个，含 `shapes`）；
- 抽查 2–3 个 json：`shapes[].label == "parking"`，`points` 是多边形顶点；
- 完成后把 json 目录原样交给 AI（不要改名、不要移动）。

## 六、注意（标注质量红线）

- **宁可少标，不可错标**——错误多边形会污染分割训练，比漏标危害大；
- 别把阴影、绿化、屋顶误当停车场；
- 边界沿硬化地面走，别框进周边；
- 这是第一批高质量正样本，直接决定分割模型能否学出来，请认真对待。
