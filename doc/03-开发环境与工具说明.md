# 开发环境与工具说明（学生版）

> 面向 5 名 SRTP 成员的上手指南。所有命令在项目根目录执行（Git Bash / PowerShell 均可）。

## 1. 环境概览

- Python 3.13（已装，虚拟环境 `.venv` 已创建）
- GPU：RTX 5060 Laptop 8GB（**必须**用 CUDA 12.8 版 PyTorch ≥2.7，旧版会报 sm_120 错误）——**训练主力**
- CPU：Intel Core Ultra 9 275HX（24 核，数据切片/预处理并行用）
- NPU：Intel NPU 3（Arrow Lake 内置）——**原型系统推理用**，第 6 周系统集成时启用：`yolo export format=openvino` → NPU 插件；训练占 GPU 期间推理走 NPU，演示不卡
- 依赖统一由 `requirements.txt` 管理

激活虚拟环境：
```bash
# Git Bash
source .venv/Scripts/activate
# PowerShell
.venv\Scripts\Activate.ps1
```

环境自检（装完所有依赖后运行）：
```bash
python scripts/00_check_env.py
```

## 2. 脚本工具链

| 脚本 | 用途 | 用法示例 |
|------|------|---------|
| `scripts/00_check_env.py` | 环境自检 | `python scripts/00_check_env.py` |
| `scripts/01_tile_imagery.py` | 大图 → 512×512 训练切片 | `python scripts/01_tile_imagery.py 影像.tif 输出目录` |
| `scripts/02_rasterize_osm_labels.py` | OSM 停车场多边形 → 标签掩膜 | `python scripts/02_rasterize_osm_labels.py data/osm/chengdu_parking_raw.json 标签.tif --bbox 104.05 30.60 104.12 30.68 --res 0.5` |
| `scripts/03_fetch_osm_parking.py` | 重新拉取任意区域 OSM 停车场 | `python scripts/03_fetch_osm_parking.py --bbox 30.57 103.98 30.72 104.18 --output data/osm/xxx.json` |

注意：`--bbox` 参数顺序不同——脚本 03 是 `南 西 北 东`，脚本 02 是 `西 南 东 北`，别搞混。

## 3. 数据目录约定

```
data/
├── imagery/        # 卫星影像原图（GeoTIFF / 大图 PNG）
├── osm/            # OSM 停车场多边形、标签掩膜
├── tiles/          # 切片输出（每个影像一个子目录）
├── labels/         # 人工精标（X-AnyLabeling 工程）
└── ge_screenshots/ # Google Earth Pro 截图（数据组维护）
```

## 4. Google Earth Pro 截图采集规范（数据组）

目的：为算法调试积累成都本地样本。**仅限内部调试使用，不得公开发布或商用。**

1. 安装官方免费版 Google Earth Pro（不要用破解版）；
2. 每次截图前记录四项信息到 `ge_screenshots/截图记录表.csv`：
   - 地点名称、中心经纬度（界面右下角有显示）、视点高度（Eye alt）、截图日期；
3. 视点高度统一 **500 m**（此高度城区实际分辨率约 0.15–0.25 m/px）；
4. 俯仰角 0°（正射垂直向下），指南针朝正北；
5. 保存图像：文件 → 保存 → 保存图像，分辨率选最大（4800×4800 需在工具→选项中设置）；
6. 文件命名：`成都_地点名_YYYYMMDD.jpg`。

## 5. 标注组上手（第 1 周练手任务）

1. 安装 X-AnyLabeling（GitHub 下载对应显卡的 GPU 版 release）；
2. 用 `data/ge_screenshots/` 里的截图练手：框选所有可见车辆（类别 `car`）；
3. 熟练后正式标注任务在第 3 周下发（吉林一号切片上的车辆框 + 停车场地块多边形）；
4. 导出格式统一 **YOLO / OBB json**（下发正式任务时附导出设置截图说明）。

## 6. 常见问题

- **Q: pip 装 torch 特别慢/失败？** A: 50 系显卡必须 cu128 源；用 `scripts/parallel_download.sh` 从阿里云镜像下轮子后本地安装（AI 已处理，遇到问题直接问）。
- **Q: GeoTIFF 打不开？** A: 用 QGIS 打开确认坐标系，别用 Windows 图片查看器。
- **Q: 切片后标签对不上？** A: 检查影像 CRS 是否为 EPSG:4326 或投影坐标系，把 `tiles.json` 发给 AI 排查。
